# Electric-Vehicle-Market-and-Performance-Analysis
Interactive Microsoft Excel dashboard for analyzing 2,000 electric vehicle records, exploring pricing trends, driving range, vehicle specifications, drivetrain distribution, and market segments using PivotTables, Pivot Charts, and interactive slicers.
⚡ Electric Vehicle Market and Performance Analysis



📊## Project Overview

An interactive Microsoft Excel dashboard designed to analyze the Electric Vehicle (EV) market using 2,000 vehicle records.

This project explores important aspects of the EV market, including vehicle pricing, driving range, drivetrain distribution, market segments, and customer ratings. Using interactive visualizations and slicers, the dashboard helps explore patterns and compare different vehicle categories.

---

🎯## Business Objective

The objective of this project is to analyze EV market data and identify patterns in:

- Analyze average vehicle prices across different body types.
- Examine driving range trends by year and brand.
- Understand the distribution of EVs by drivetrain type.
- Analyze the distribution of vehicles across different market segments.
- Explore customer ratings and overall EV market performance.
- Support better data-driven decision-making through interactive visualizations and filters.

---

📈 ## Key Performance Indicators

The dashboard includes the following KPIs:

- Total EV Records
- Average Vehicle Price
- Average Driving Range
- Average Customer Rating

---

📊 Dashboard Features

The interactive dashboard includes:

- Interactive KPI cards showing Total EV Records, Average Vehicle Price, Average Vehicle Range, and Average Customer Rating.
- Average Price analysis by Vehicle Body Type.
- Average EV Range analysis by Year.
- Brand-wise Average EV Range comparison.
- EV Count distribution by Drivetrain Type.
- EV Records analysis by Market Segment using a Treemap.
- Dynamic visualizations that update based on selected filters.
- Interactive slicers for filtering the data by:
  - Vehicle Brand
  - Model Year
  - Body Type
  - Drivetrain Type
